# **推荐序**
All-in“**峰终定律**”：一段经历最让人印象深刻的，是它的巅峰瞬间——最好和最坏的体验——和结束瞬间。

+ 体验时代，已经到来！
+ 体验式可以被设计的。
+ 心理学中“**峰终定律**”：一段经历最让人印象深刻的，是它的巅峰瞬间——最好和最坏的体验——和结束瞬间。
+ 在现在这个时代，消费的趋势已经从“购买东西”转向了“购买体验”。
+ 打造让用户难忘的峰值瞬间的四个因素：欣喜、认知、荣耀和连接。

 

## <font style="color:#2E75B5;">第一章</font><font style="color:#2E75B5;">决定时刻</font>
+ 两个目标：
    - 第一，我们想要深入研究决定时刻，并找出这些时刻所共有的特征。
    - 第二，我们想要向读者展示该如何利用这些要素打造决定时刻。
+ 峰终定律：记住峰值，难忘结尾。
+ 人们会根据两个关键时刻来评判一段体验的好坏：
    - （1）最好或是最坏的时刻，也就是“峰值时刻”。
    - （2）结尾，这种现象被心理学家称为“峰终定律”。
+ 评判体验时，并不会取每分钟感受的平均值，而是容易记起意义重大的时刻：高峰，低谷，以及转折点。
+ 所谓决定时刻，指的是一段即令人难忘又意义重大的短暂体验。（这里短暂是相对概念）。
+ 决定性时刻由以下4种因素中一种或者几种构成：
    - **欣喜**：决定性时刻要高于日常生活，因为它不仅能带来稍纵即逝的快乐，也能带来让人记忆深刻的喜悦，欣喜时刻是超越日常生活的体验，是名副其实的“超凡”之感；
    - **认知**：决定性时刻能够重新改写我们对于自己或对于世界的认识；
    - **荣耀**：决定性时刻能够记录下我们最辉煌的状态；
    - **连接**：重要时刻因我么鱼他人分享而变得更加意义非凡。
+ EPIC（欣喜elevation，荣耀pride，认知insight以及连接connection）

 

## <font style="color:#2E75B5;">第二章</font><font style="color:#2E75B5;">瞬间思维</font>
+ 思维瞬间：在单调的生命中，寻找应该凸显的节点。
+ 三个值得凸显的事件：转变事件，里程碑事件，以及低谷事件。
+ 对于里程碑式的时刻，我们天生就对它有一种渴望。
+ 低谷需要填平。
+ 低谷有时候还可能反转为尖峰。
+ 转变事件需要凸显，里程碑事件需要纪念，而低谷事件需要被填平。
    - 转变事件：升职，入学第一天，项目终结和开始
    - 里程碑事件：退休，出人意料的成就
    - 低谷事件：处理负面反馈，失去所爱之人。

 

# **第一部分****<font style="color:#1E4E79;">欣喜时刻</font>**
**All****-in****如何打造决定性时刻？**

+ 让欣喜升级：打破脚本，提高刺激性，提升感官享受；
+ 让认知升级：被现实绊倒（对别人提出的意见抵触），突破认知；
+ 让荣耀升级：多设里程碑，认可他人；
+ 让连接升级：打造共同使命感。

 

## <font style="color:#2E75B5;">第三章 峰值时刻</font>
+ 绝大部分平淡无奇，但偶尔会让人拍手叫绝。
+ 峰值时刻是应该提前计划、用心投资的，是应该好好营造的。
+ 研究表明，当消费者在使用你的产品或者服务时遇到问题而联系你的时候，你应当专注于防守。也即是说，你应该关注解决实际问题，而不是试着“讨顾客欢心”。
+ 想要超越消费者的期待，打造令人难忘的体验，你就需要对服务过程中的行为和人际交往下手。
+ 我们容易对出现的问题和负面信息耿耿于怀。
+ 如何打造峰值体验？

你要做的就是创造出一个欣喜、认知、荣耀以及/或者连接因素在内的积极时刻。

+ 在一个时刻中加入欣喜因素做到以下三点：
    - 第一，提升感官享受
    - 第二，增加刺激性
    - 第三，突破脚本（就是指打破人们对于某种体验的预期）
+ 提升感官享受，是指将现实世界的“音量调高”，婚礼的音乐和鲜花。
+ 增加刺激性，指的是添加一些有助于提升效率的压力。比赛，竞技，支付宝答答星球。
+ 请务必提防所谓“合理性”对灵感的磨灭。
+ 人生的一大陷阱：日子一天天过去，一年就这样过去了，二我们还是没有进行那场早该进行的对话，没有为我们的学生打造出那个峰值时刻，没能领略北极光之美。

 

## <font style="color:#2E75B5;">第四章</font><font style="color:#2E75B5;">打破脚本</font>
+ 如果想要为你的消费者打造值得铭记的时刻，你就必须要打破脚本。
+ 一个解决方案就是加入一下随机性的因素。
+ 仅仅靠打破常规，我们就能创造出更多的峰值体验。
+ 记忆隆起：人对于某段生活经历的记忆曲线不同于传统的回忆量递减的遗忘曲线，而是出现了回忆量增加的情况。
+ 新鲜感甚至能够改变我们对于时间的感知。
+ 惊喜能够使时间延长，恐惧和专注使得时间仿佛延长。
+ 对于那些因未来不如过去更让人记忆深刻二发愁的人，我们的建议就是，要尊重“多样性是生活的调味品”这句老话的智慧。
+ 小小的新鲜感的确有着巨大的威力，但还是要学会读懂属于自己的脚本。
+ “党万事确定时，我们感到最为安心，但当万事不定时，我们却最有活力。”

 

## <font style="color:#2E75B5;">欣喜时刻</font><font style="color:#2E75B5;">-</font><font style="color:#2E75B5;">要点小结</font>
+ 欣喜时刻指的是超越平常的体验。
+ 打造更多欣喜时刻的3种原料：提升感官享受；增加刺激性；打破脚本。
+ 打破脚本的时刻对于企业的改变起着关键作用。
+ 打破脚本的时刻，也是我们人生中记忆最为深刻的时刻。
+ 创造欣喜时刻也仍是一件难事，虽然困难，但“峰值时刻”仍然值得打造。
+ **如何打造决定性时刻？**
    - 让欣喜升级：打破脚本，提高刺激性，提升感官享受；
    - 让认知升级：被现实绊倒（对别人提出的意见抵触），突破认知；
    - 让荣耀升级：多设里程碑，认可他人；
    - 让连接升级：打造共同使命感。

 

# **第二部分****<font style="color:#1E4E79;">认知时刻</font>**
All-in想要打造自我认知时刻，就需要突破自我，也就是把自己暴露于风险之下、置身于新环境中。

## <font style="color:#2E75B5;">第五章 被现实绊倒</font>
+ 真相让人觉醒
    - 与现实的碰撞往往会给人的情感带来一记重拳。当你得到了个未曾预料，却打从心眼里知道是正确的顿悟的时候，你就与现实产生了碰撞。这个决定性时刻能够在须臾之间改变你看待世界的方式。
    - 明确的认知、用时简短、由受众自己发现，这份由三种元素组成的配方为我们提供了一份蓝图，供我们在希望别人面对不愿面对的真相时使用。
+ 关注问题而非解决问题
+ 在人生中的某些阶段，只有被现实“绊倒”，我们才能找到自己的立足点。

 

## <font style="color:#2E75B5;">第六章</font><font style="color:#2E75B5;">突破认知</font>
+ 更好的方法是冒险尝试，并从经验中提炼答案，而不是空坐着发呆。行动往往能带给我们认知，而认知却不总能引发行动。
+ 认识自我，明白自己想要什么，理解自己的能力，是一个持续一生的过程。
+ 助推认知：“高标准+信心”和“方向+支持”
+ 高标准+信心+方向+支持=自我认知加深
+ 突破自我必定能带给你的不是成功，而是学习和成长。这必定是一种自我认知，必定能让你得到一些生命中最重要也最让人烦的问题的答案：我们想要的是什么？我们能做些什么？我们能成为什么样的人？我们又能示受什么样的代价?

 

## <font style="color:#2E75B5;">认知时刻</font><font style="color:#2E75B5;">-</font><font style="color:#2E75B5;">要点小结</font>
+ 认知时刻能让我们收获认知，实现转变。
+ 认知时刻不一定是因缘偶发的。想要为他人打造认知时刻，我们可以引导他们“被现实绊倒”，也就是启发他们收获震撼人心的感悟。
+ 被现实“绊倒”需要：明确的认知；用时简短；由观众自己去发现；
+ 想要打造自我认知时刻，就需要突破自我，也就是把自己暴露于风险之下、置身于新环境中。
+ 能够引导人们产生自我认知的导师配方：高标准+信心+方向+支持
+ 突破自我带来的不是成功，而是成长。

 

# <font style="color:#1E4E79;">第三部分 荣耀时刻</font>
All-in想要打造更多的荣耀时刻，有三个实用的方法：认可他人；多设里程碑；锻炼勇气；第一种方法能为他人打造决定性时刻，后两种方法则让我们为自己打造决定性时刻；

 

## <font style="color:#2E75B5;">第七章 认可他人</font>
+ 在为他人打造荣耀时刻的所有方法中，最简单的一种要数认可他人了。
+ 重要的并不是具体的方式，而在于是否真诚。

 

## <font style="color:#2E75B5;">第八章</font><font style="color:#2E75B5;">多设里程碑</font>
+ 想要体验更多的决定性时刻，我们就需要重新思考设立目标的方式。
+ 升级：为目标设置关卡和层级
+ 回顾以往，挖掘成就
+ 明智的管理思维：用小目标支撑大目标
+ 视觉标志出发荣耀时刻，触及到里程碑的时候，荣耀感会油然而生。
+ 努力跨越终点线能够带来成功，而里程碑的意义则在于强迫我们作出努力，因为
    - 这些里程碑式触手可及的；
    - 之所以选择这些里程碑，是因为这些里程碑只得我们伸手去够；
+ 里程碑标志着那些能够征服，也值得征服的目标。

 

## <font style="color:#2E75B5;">第九章</font><font style="color:#2E75B5;">锻炼勇气</font>
> _勇气是对恐惧的抵抗、对恐惧的掌控，而不是无所畏惧。__——__马克__·__吐温_
>

+ 缓解恐惧症（非理性恐惧）最有效的疗法之一是暴露疗法。
+ 勇气并不仅仅是压制恐惧感，还包括掌握在危机情形之下该如何反应的知识。
+ 一个勇敢之举能够为另一个勇敢之举提供支撑。

 

## <font style="color:#2E75B5;">荣耀时刻</font><font style="color:#2E75B5;">-</font><font style="color:#2E75B5;">要点小结</font>
+ 想要打造更多的荣耀时刻，有三个实用的方法：
    - 认可他人；多设里程碑；锻炼勇气；
    - 第一种方法能为他人打造决定性时刻，后两种方法则让我们为自己打造决定性时刻；
+ 想要为我们自己打造荣耀性时刻，就应该让有意义的里程碑翻倍-也就是重新规划漫长的旅途，在其中设置许多条“中间线”。
+ 锻炼勇气能够让我们“事先储存”好该做出的反应。
+ 勇气是有感染力的，我们的行动或许能够造就他人的决定性时刻。

 

# <font style="color:#1E4E79;">第四部分</font><font style="color:#1E4E79;">链接时刻</font>
All-in 想要在团队中激发彼此产生联系，我们就必须创造共同的意义。有三个方法：打造让大家步履一致的时刻；点明共有的难处；为之赋予意义。

 

## <font style="color:#2E75B5;">第十章 共同使命感</font>
+ 对于日常交流和合作而言，远程的沟通非常实用。但是，重大的时刻就需要大家共同亲身参与。人们的亲自到场能够将抽象的创意转化为实实在在的社会性时间。
+ 如果你想要成为一个如钢精水泥般坚不可摧的团队的一员，那就共同承担起一项意义深远的艰巨任务。
+ 使命感：引领激情，无往不胜
+ 使命感比激情更有效。激情属于一个人，既能给我们带来动力，又能让我们处于孤立之境，因为每个人的激情毕竟有所不同。与之相反，使命感却是能够拿来分享的东西，足以成为一股将团队团结在一起的凝聚力。
+ 使命感能够激发“超越日常工作”的行动。

 

## <font style="color:#2E75B5;">第十一章</font><font style="color:#2E75B5;">加深感情</font>
+ 给予回应让感情更坚固
+ “回应”包含三个因素：理解，肯定，关心
+ 给予回应涉及归属感、自尊心、心理健康及一大堆积极正面的元素。
+ 想要打造更多的连接时刻，我们就必须多给对方一些回应。

 

## <font style="color:#2E75B5;">连接时刻</font><font style="color:#2E75B5;">-</font><font style="color:#2E75B5;">要点小结</font>
+ 想要在团队中激发彼此产生联系，我们就必须创造共同的意义。有三个方法：
    - 打造让大家步履一致的时刻；
    - 点明共有的难处；
    - 为之赋予意义。
+ 坚定的使命感比激情四溢更能带来高效的表现。
+ 所谓给予回应，就是相互之间的理解、肯定和关心。

 

## <font style="color:#2E75B5;">第十二章</font><font style="color:#2E75B5;">宝贵时刻</font>
+ 一旦意识到特殊时刻的重要性，我们就很容易发现打造这些时刻的机会。
+ 抓住顿悟，立即行动
+ 通过打造些许珍贵的时刻，巅峰日常生活和工作中让人转瞬即忘的枯燥和单调。
