# 项目背景
1.原有专题模板存在诸多遗留体验不良的问题，逐个修复造成浪费资源，在性能&拓展上上有瓶颈； 2.原有专题模板的管理平台无权限管理且功能设置混乱； 3.为满足后期企业业务拓展需要，设计一款高复用性且稳定的内容营销工具更有利于向业务前台赋能；



项目岗位：

共4人：产品1名、设计1名、前端1名、后端1名





# 项目目标
1.重构内容营销平台的功能结构与业务逻辑； 2.构建全新的内容营销平台，涵盖用户端前台、管理端前台等版块； 3.赋予平台更高的自由定制能力，减少开发人员与设计人员重复机械性的投入； 4.明确专题作为“内容展示与流量分发的中转站”的定位，通过组件的精简为专题减负；
