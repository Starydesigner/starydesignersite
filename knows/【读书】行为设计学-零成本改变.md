三、书籍精华

+ 人类大脑内部时钟有两个相互独立的运作系统。第一个就是情感面，这部分自我属于天性本能，能够感知痛苦，获得快乐；另一个是理智面，也称为反思系统或者自觉系统，这部分自我能够深思熟虑，能够条分缕析，能够思索未来。
+ 改变三部曲：

1.指挥骑象人

看似心生抵触，实则方向不明，因此必须提供清晰明确的方向。

2.激励大象

看似懒于改变，实则筋疲力竭。气象人不可能考强迫来让大象长时间服从，因此必须从情感面入手，让大象愿意配合你，一同上路。

3.营造路径

看似是人的问题，实则为情境问题。我们把情境（包括周围环境）成为路径。路径营造好后，即使不考虑气象人和大象，改变都会更容易发生。

 

**零成本改变行动框架**

**指挥骑象人**

找到亮点：找出成功案例，复制推广亮点。

制定关键举措：无须高膽远瞩，着眼于关键步骤 。

指明目标：预先指明方向和原因大有助益。

 

激励大象

找到感觉：仅停留在知道层面未必能改变，必须形成感觉。

缩小改变幅度：分解改变步骤，消除大象的恐惧。

影响他人：建立新认同感，灌输成长心态。

 

营造路径

调整环境：情境影响行为，设法改变环境。

培养习惯：形成习惯则不费力，设法鼓励培养习惯。

着急同伴：行为有传染力，设法号召众人。

 

四、书籍随笔

# <font style="color:#1E4E79;">第一部分</font><font style="color:#1E4E79;">指挥骑象人</font>
## <font style="color:#2E75B5;">第一章</font><font style="color:#2E75B5;">找到亮点</font>
+ 要实现改变，必须想方设法指挥骑象人，告诉他去哪里、做什么、追求什么目标。
+ 骑象人否认分析能力永无止境。当骑象人过于活跃，人们甚至可能把成功当成问题。
+ 正面评价与负面评价的不对称性。在人们眼中，他人的坏事总是比好事给人留下更深的印象。人们更关心坏事，更长谈坏事，对坏事的记忆也更深刻。
+ 我们的骑象人不应该聚焦问题，而应该聚焦对策。
+ 我们必须把分析负面问题的考古式方法，转变为寻求亮点、传播亮点的解决思路。

## <font style="color:#2E75B5;">第二章</font><font style="color:#2E75B5;">制定关键举措</font>
+ 决策是骑象人的领地，做决定需要自我监督和自我控制，这会消耗骑象人的能量。

> _我们将不堪重负。选择不再带来自由，反而会削弱自由，甚至可以说压制自由。_
>
> _——__《选择的悖论》_
>

+ 改变带来的一连串选择会造成新的不确定性。
+ 改变中最困难的部分，也是最容易导致决策瘫痪的部分，恰恰是细节。
+ 你不可能制定每一步棋着，也无需制定所有棋着，关键在于制定关键举措。
+ 当你希望他人接受想你的行为时，就应该解释清楚什么是“新行为”。
+ 假如无法让改变的目标落地，无法将改变的抽象理念转化为具体的行动，你就不可能准备好引领一场转变。
+ 指示清晰明确，便能消除抗拒。

## <font style="color:#2E75B5;">第三章</font><font style="color:#2E75B5;">指明目标</font>
+ 描绘一个引人注目的终点时，也是帮助骑象人客服他一个重大缺陷——在分析中迷失的倾向。
+ 聪明目标——明确、可衡量、可操作、相关的和及时的目标
+ 聪明目标比较适合于稳定的环境，而不适合变革时期，因为聪明目标已经预先假定这个歌终点具有追求价值。
+ “终点明星片”具有双重效用：告知骑象人去往何处，晓示大象此行的价值。
+ 人类的惰性：将失败自我合理化
+ 问题的关键在于，长期目标需要和短期关键步骤结合起来。
+ 改变开始后，不要执迷于中间的旅途，因为现实往往和预想的有差别。真正重要的是一个有力的开始，一个有力的结尾，然后赶快上路。
+ 一方面，骑象人富有远见卓识，愿意为长期目标而作出短期牺牲（这正是骑象人为何总与大象对抗的原因：大象往往看重眼前的享受）；头脑清晰，善于谋略，拿到路线就能按图索骥。另一方面，骑象人也有诸多缺点：力量有限，遇到指向不明或选择过多的状况就会陷入瘫痪状态，并且过分聚焦于问题而非对策。

 

# <font style="color:#1E4E79;">第二部分</font><font style="color:#1E4E79;">激励大象</font>
## <font style="color:#2E75B5;">第四章</font><font style="color:#2E75B5;">找到感觉</font>
+ 问题的核心总是于改变人们的行为有关，而在最成功的案例当中，行为改变大多诉诸人的情感面。
+ 分析性工具最能派上用场的情境是“变量已知，假设极少，目标明确”。
+ 改变发生的顺序不是分析➡️思考➡️改变，而是看见➡️感觉➡️改变。
+ 负面情绪多半会给我们的思维带来“窄化效应”；正面情绪的作用与负面情绪相反，反倒能“拓展和充实”我们的整体的思维和行动。

 

## <font style="color:#2E75B5;">第五章</font><font style="color:#2E75B5;">缩小改变幅度</font>
+ 鼓励人们采取行动的办法之一，就是让对方觉得自己离目标越来越近了。有所进展的感觉很重要。
+ 不要过分关注改变将要带来的不同之处，而应该设法提醒人们已经克服的困难。
+ 要让一头不情愿大大象迈开脚步，你必须缩小改变的幅度。
+ 将奇迹予以量化的另一个好处是，消除整个过程的神秘感。
+ 我们花费太多的时间和精力预测未来事件，抚平未来伤痛，预防错失眼前时机造成的后果。我们为未来设定的任务太过巨大，留给自己的只剩下筋疲力竭、不堪重负和心烦意乱。

 

## <font style="color:#2E75B5;">第六章</font><font style="color:#2E75B5;">影响他人</font>
+ 认同是影响人们决策方式的关键因素，违背认同的改变方案往往会以失败告终。
+ 认同感几乎在所有改变中都扮演着重要的角色；人们愿意培养新的认同感，只是认同感的培养要从小处开始。
+ 你必须建立起对失败的预期，不是预期整个任务的失败，而是预期途中会遭遇失败。
+ 成长心态其实是对抗失败主义的缓冲，并且把失败包装成改变过程中不可避免的自然产物。
+ 动力来自感觉，但是感觉并不足以激起改变；动力还来自信心，但是必须相信自己有能力完成改变。
+ 两条建立信心的途径：你可以缩小改变的幅度，也可以影响需要改变的人。

 

# <font style="color:#1E4E79;">第三部分 营造路径</font>
## <font style="color:#2E75B5;">第七章</font><font style="color:#2E75B5;">调整环境</font>
+ 基本归因错误：是指我们总喜欢把他人归咎于对方的个人特质，而不是对方所处的情境。
+ 只要稍微调整一下环境，正确行为很快就会出现。改变的不是人，而是情境；看似是人的问题，实则为情境问题。

 

## <font style="color:#2E75B5;">第八章</font><font style="color:#2E75B5;">培养习惯</font>
+ 环境对我们产生的微妙作用之一，就是强化（或者淡化）我们的习惯。
+ 行为触发扳机可“避免目标受到各类诱惑、坏习惯和其他目标的干扰。”
+ 行动触发扳机一定要足够具体，足够明确，才能中断人们在日常生活中的意识流。
+ 适用的情境越困难，行动触发扳机越有效，因为骑象人在这些场合消耗的自我控制能量越多。
+ 行动触发扳机的真正作用是培养“速成习惯”。
+ 该如何培养有助于实现改变的习惯呢？
    - 第一，这个习惯必须能推动你的任务。
    - 第二，这个习惯实现起来必须相对容易。
+ 在追求转变的旅程中，最困难的部分在于维持前进的动力，保证大象始终走在转变的路上。

## <font style="color:#2E75B5;">第九章</font><font style="color:#2E75B5;">召集同伴</font>
+ 当你指挥大象走在不熟悉的路径上时，大象很可能会追随其他同伴的脚步。
+ 如果你希望改变组织文化，你首先得召集所有改革者。改革者需要一处自由空间和不受守旧者干涉的时间来相互协调。
+ 营造路径的工具：首先调整环境；其次培养好习惯，最后召集同伴。
